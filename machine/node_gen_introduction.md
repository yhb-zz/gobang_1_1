## 介绍
节点生成算法本质上是一个比较弱的五子棋算法, 这个算法棋力差但速度快  
用于对节点进行排序以便更好地剪枝
## 思路
对于某一个空位, 如果它八个方向的一格(两格)内有棋子, 就进行打分  
对所有进行打分的格子按照分数由高到低排序  
###### 打分思路
对于一个空位, 先只看黑棋进行打分, 再只看白棋进行打分, 最后将两者分数加起来  
只看某个颜色的棋子时, 另一个颜色的棋子视为 "边界"  
只看一种颜色时, 先对四行(横, 竖, 两个斜行)分别打分  
再根据这四行的情况进行加分  
对一行进行打分时, 需要考虑这一行两个方向四个位置的状态(黑棋/白棋/空位)  
例如: (黑棋记为 1 白棋 2 空位 0) 

> 0 0 0 2 1 1 0 0 2 2 2 0 0

是我们考虑的颜色记为 1, 空位记为 0, 不是我们考虑的颜色视为 "墙"  
以第 8 个位置为例, 我们考虑的颜色是白色, 墙记为 ">" / "<"
那么我们会提取 

> \> 0

> 1 1 1 0

在远端补上一个 1, 避免混淆(如 > 0 0 和 > 0 0 0 等类似的情况)  

> \> 1 0

> 1 1 1 0 1

我们不看墙, 把数字部分按照远端到近端排列(这里只需要对第二个进行翻转)

> 1 0

> 1 0 1 1 1

看作二进制, 再转化为对应的十进制, 在table.txt里面有对应的分数  
(注意: 由于对称性, table.txt里面只有大约一半)

## 给分标准
* 单行给分:
    + T0: 连五点(score >= 10^5)  
            (先统一为 10^5)  
            己方: 10^6  
            敌方: 10^5  
    + T1: 活四点(score >= 10^3)  
            (先统一为 10^3)  
            己方: 10^4  
            敌方: 10^3  
    + T2: 活三点 冲四点  
            冲四点: 105  
            活三点: 100  
            跳活三点: 95  
    + T2.5: 活二点 眠三点 可跳活三点  
            活二点(可活三): 20  
            眠三点(可冲四): 20  
            可跳活三点: 15  
    + T3: 可眠三:  
            1 分  
* 单点给分加成:  
    + T0(舍弃T0以下): 连五点  
            无加成  
    + T1(舍弃T1以下): 活四点/双冲四点:  
            活四点: 无加成  
            双冲四点: 按照活四分数加分  
    + T2: 三四点/三三点:  
            三四点:加 200 分  
            三三点:加 150 分  
    + 额外加分(由活二点/眠三点/可跳活三点的数量 n 加分):  
            加 10 * ( 2 ^ n ) 分
